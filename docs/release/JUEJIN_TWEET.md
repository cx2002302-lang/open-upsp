# 掘金沸点文案

## 沸点 1（项目介绍）

🔥 做了一个让 AI Agent 拥有"长期记忆"的开源项目

不是简单的向量数据库，而是用 Zettelkasten（卢曼卡片盒）做真正的知识图谱：
• 原子笔记 + 双向链接
• 夜间自动蒸馏归档
• 渐进式人格进化（聊满10轮解锁新能力）

GitHub：github.com/cx2002302-lang/open-upsp

#开源 #AI #OpenClaw

---

## 沸点 2（技术亮点）

给 AI Agent 做了一套 RPG 式的成长系统 💡

前10轮：保守安全，只回答明确问题
10轮后：主动发现关联、有幽默感、能执行复杂工作流

用「信任度」控制解锁，不是写死的规则，而是动态演化的

npm install -g open-upsp

---

## 沸点 3（Before/After 对比）

❌ 普通 Agent：
"上次我们聊到..."
"您好！我可以帮您分析..."

✅ 有 open-upsp 的 Agent：
"上次我们聊到 React 性能优化，你总结了 useMemo 的3种误用场景。要继续深入虚拟列表吗？"

这就是长期记忆的力量 🧠

详细实现 👉 github.com/cx2002302-lang/open-upsp
